# Envio

Envio is a high-performance blockchain data indexing platform providing
developers with the fastest and most flexible way to access on-chain data.
Its core products — HyperIndex, HyperSync, and HyperRPC — enable real-time
and historical indexing across 100+ EVM networks and beyond.

## APIs

- **HyperIndex GraphQL API** — auto-generated GraphQL endpoints for indexed smart contract events
- **HyperSync REST API** — high-speed data retrieval layer (up to 2,000x faster than JSON-RPC) across 100+ chains
- **HyperRPC JSON-RPC API** — drop-in JSON-RPC replacement optimised for data-intensive operations
