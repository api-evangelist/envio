A step-by-step guide to building a HyperIndex indexer for the Sei blockchain that tracks USDC Transfer and Approval events. The tutorial covers scaffolding a project from an ERC20 template, configuring it for Sei mainnet (chain ID 1329), defining a GraphQL schema, writing event handlers, and querying indexed data via a local API. Setup requires Node.js, pnpm, Docker, and an Envio API token, streaming data into PostgreSQL served through GraphQL.
